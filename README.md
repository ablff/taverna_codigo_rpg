# Taverna do Código - Aventura em Texto

Um jogo de RPG em formato de texto desenvolvido em Python, com foco em narrativa e gerenciamento de dados. O projeto simula a experiência de uma taverna clássica, onde as escolhas importam e o progresso do personagem é salvo de forma persistente.

## Tecnologias e Conceitos Aplicados
* **Python 3:** Lógica central, estruturação de menus e Orientação a Objetos (POO).
* **SQLite:** Banco de dados relacional utilizado para a persistência de dados (salvamento de status, itens e ouro do jogador de uma sessão para outra).

## Foco de Aprendizado
Este projeto foi construído para solidificar conceitos de Engenharia de Software e programação estruturada. O maior desafio e aprendizado esteve na manipulação de arquivos e na integração do código local com um banco de dados real para realizar operações de leitura e escrita.

## Como jogar
1. Clone este repositório para o seu computador:
   git clone https://github.com/ablff/taverna_codigo_rpg.git

2. Pelo terminal, navegue até a pasta do projeto e execute o arquivo principal:
   python main.py
